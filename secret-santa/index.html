How it works

The draw shuffles everyone so nobody gets themselves and nobody gets a name you blocked. With 4 or more people it also avoids two people drawing each other, so every gift is a surprise. The match is scrambled into each link, so there is no server and no account, but it is not real encryption: it keeps an honest group honest, not a hacker out. Anything after a colon on a name line (like "Sam: coffee, size M") shows up as wish hints in the link of whoever draws Sam. Your list is saved on this device only, so you can come back and resend a link.
